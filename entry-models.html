Where to start

This is a ladder, not a menu. Each rung teaches exactly one new concept and reuses everything below it: bracket mechanics → levels → the open → liquidity → trend flow → delivery. You trade one model at a time until your journal proves you execute it by rule — then the next rung unlocks.

Tier 1 · Beginner
Trigger Candle · First Touch · OR Raid
Naked chart + hand-drawn levels + the daily level drop. No indicators. Gate: 10 reps on Model 0, then 20 journaled reps per model, ≥80% rule-compliance.
Tier 2 · Intermediate
Sweep & Reclaim · Flow Pullback
Script access unlocks here — the 8BF toolset is earned, not given. Same gate: 20 reps per model, ≥80% compliance.
Tier 3 · Advanced
CISD
The full stack: levels + liquidity + displacement. Session variants (London, Asia) open up here too.
◎
The one-line doctrine: an entry model is a permission system, not a prediction system. It tells you the only moments you are allowed to act — everything outside those moments is flat. Mastery = the model fires and you execute it identically every time.
